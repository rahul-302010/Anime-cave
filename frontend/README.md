# Anime Cave — Frontend

This is the React + Vite frontend for Anime Cave. It connects to the backend at `http://127.0.0.1:8000` via the Vite proxy.

## Quick start

```bash
cd frontend
npm install
npm run dev
```

Open: http://127.0.0.1:5173

## Notes
- Uses tokens in `src/styles/tokens.css` generated from the provided reference image.
- Hero uses a lightweight card; replace poster placeholders with real images in `public/`.

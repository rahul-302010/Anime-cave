## Design Inspiration
- https://github.com/voltagent/awesome-design-md — Curated collection of design.md files from top products; use to study how Linear/Vercel structure design docs.
- https://getdesign.md/ — Gallery of real design.md examples (Linear, Vercel, Claude) for tone and token organization.
- https://www.awwwards.com/ — Benchmark for premium web aesthetics and Three.js hero treatments.
- https://codepen.io/ — Quick prototypes for glass cards, glow, and motion micro-interactions.
- https://css-tricks.com/ — Practical CSS for backdrop-blur, grid, and focus states.

## Frontend / Visual
- https://threejs.org/ — Three.js docs for hero canvas, points, and parallax performance.
- https://nochev.github.io/hls.js/docs/html/ — hls.js API for HLS playback, buffer tuning, and error handling in browser.

## Backend / Media
- https://github.com/yt-dlp/yt-dlp — yt-dlp extractor and external-downloader integration for resolving streams.
- https://aria2.github.io/manual/en/html/ — aria2c manual for split, per-host limits, and retry flags.
- https://github.com/videolan/vlc — VLC docs/HTTP interface for local player bridge fallback.
